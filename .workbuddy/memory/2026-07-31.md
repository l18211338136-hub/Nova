## AuthAuditLog 的 TenantId 改为 Finbuckle 阴影属性
- 用户审查上次提交（b92e09c）时认为 `AuthAuditLog.TenantId` 显式属性多余。核实：User/Role/Menu 等多租户实体**都不声明** `TenantId`，全靠 `ApplyTenantIsolationByDefault()` 自动生成阴影属性。`AuthAuditLog` 额外显式声明属于不一致。
- 已改为与项目一致：删除 `AuthAuditLog` 实体显式 `TenantId` 属性 + 构造函数 `tenantId` 参数（`src/Modules/Identity/Nova.Modules.Identity.Domain/AuthAuditLog.cs`）；`AuthAuditEventConsumer` 构造 `AuthAuditLog` 时去掉 `evt.TenantId` 实参（但保留 `evt.TenantId` 用于 `IMultiTenantContextSetter` 切上下文）；查询端点 `IdentityODataEndpoints.cs` 的 `ProjectToType` 改为显式 `Select` + `EF.Property<string>(l, "TenantId")` 读阴影属性（DTO 仍保留 TenantId 字段）。
- 验证：`dotnet build Nova.Modules.Identity.Api` 0 错误（3 个预存警告无关）。
- 关键结论：`AuthAuditLog` 未实现 `IGlobalEntity`，`ApplyTenantIsolationByDefault()` 仍对其 `IsMultiTenant()`，阴影属性保证数据库 `TenantId` 列与租户隔离**不变**。删除显式属性不影响迁移 schema，所缺的 `AddAuthAuditLog` 迁移内容不变，仍需按 README 生成。

## AuthAuditLog 迁移缺 TenantId 列 —— 根因与修复（重要）
- 用户生成 `AddAuthAuditLog` 迁移后发现 `AuthAuditLogs` 表**没有 TenantId 列**，审计功能无法按租户隔离，且 `EnforceMultiTenant()` 保存时会冲突。
- **根因**：`ApplyTenantIsolationByDefault()` 用反射调用 `IsMultiTenant<T>()`（泛型方法），对 `AuthAuditLog` **未能**生成 `TenantId` 阴影属性；而 `User`/`Role`/`Menu` 是在 `OnModelCreating` 里**显式**调 `.IsMultiTenant()`（非泛型扩展方法，会自动创建阴影属性），所以它们有 TenantId。迁移 `Up()` 建表时无该列，但快照也完全没有该属性（确认过 Designer 的 AuthAuditLogs 块无 TenantId）。
- **修复**：在 `IdentityDbContext.OnModelCreating` 中显式注册 `builder.Entity<AuthAuditLog>(b => { b.ToTable("AuthAuditLogs"); b.HasKey(a => a.Id); b.IsMultiTenant(); });`（位于 Menu 配置之后、`ApplySoftDeleteQueryFilter()` 之前）。实体类仍保持无显式 TenantId 属性（阴影属性，符合用户"删掉显式属性"诉求）。
- **迁移重建流程**（本次实战）：该迁移此前已被应用到 DB，故 `migrations remove` 直接拒绝。正确顺序：
  1. `dotnet ef database update 20260726052803_RemoveIdentityUniqueConstraints -c IdentityDbContext -p src/Modules/Identity/Nova.Modules.Identity.Infrastructure -s src/Host/Nova.WebApi`（先回滚 DB，删除 AuthAuditLogs 表）
  2. `dotnet ef migrations remove -c IdentityDbContext -p ... -s src/Host/Nova.WebApi`（移除迁移文件 + 还原快照）
  3. `dotnet ef migrations add AddAuthAuditLog -c IdentityDbContext -p ... -s src/Host/Nova.WebApi`（重新生成，现含 TenantId 列 `type:"text", nullable:false`）
- **注意**：git bash 中 `\` 是转义符，README/命令里的反斜杠路径会被吞掉导致 "Unable to retrieve project metadata"，必须用**正斜杠**路径。
- **Defender 锁 bin/obj**：临时把 `<ArtifactsPath>` 和 `<GenerateDocumentationFile>false</GenerateDocumentationFile>` 写进 `Directory.Build.props` 让 EF 内部构建走隔离目录，跑完**必须还原**（已还原）。
- 新迁移 `20260731142507_AddAuthAuditLog.cs` 已生成并验证含 TenantId 列；启动应用 `MigrateAsync()` 会自动建表。

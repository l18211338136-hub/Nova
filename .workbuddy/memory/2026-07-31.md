## 项目整体理解（首次探索）
- 用户请求"了解整个项目"。通过 Explore 子代理对全仓做了 thorough 级扫描，并核对了根文件与目录。
- 核心结论：Nova 是一个 **.NET 10 模块化单体（Modular Monolith）骨架**，AI Agent 平台是**命名意图而非实现**——`Nova.Framework.AI` 及 13 个业务模块（Agent/Chat/MCP/Memory/Model/Workflow/Knowledge/Prompt/Tool/Workspace/Billing/Storage/Audit）均为空占位，仅 Identity（完整四层）、Multitenancy（2 层）、Notification（3 层）有真实代码。
- 技术栈：EF Core 10 + PostgreSQL(Npgsql) + Finbuckle.MultiTenant + ASP.NET Identity + JWT + MassTransit Mediator(CQRS) + FusionCache + Hangfire + OData + Scalar/OpenAPI；前端 src/Web/admin 为 React19+Vite+shadcn-admin，Orval 自动生成 API 客户端。
- 已写入 `MEMORY.md` 长期项目笔记。

## 关键构建 workaround（重要，环境约束）
- 本机 Visual Studio 持续构建整个解决方案，且与 Windows Defender/索引器抢夺 `bin/obj`、特别是 `Nova.UnitTests.xml`（CS0016 Access is denied）。
- **可靠解法**（每次跑测试都加）：唯一时间戳 ArtifactsPath + `-p:GenerateDocumentationFile=false`（消除 xml）+ `--disable-build-servers -p:UseSharedCompilation=false -p:_msCoverageSourceRootTargetName=__none__`。
  例：`dotnet test tests/Nova.UnitTests/Nova.UnitTests.csproj --filter "..." -p:GenerateDocumentationFile=false -p:ArtifactsPath="D:/Github/Nova/artifacts-run-$ts" --disable-build-servers -p:UseSharedCompilation=false -p:_msCoverageSourceRootTargetName=__none__`
- NuGet 源拉不到 `MassTransit.Testing`（B 档本就不需要，未引入）。
- 临时产物落在 `D:/Github/Nova/artifacts-run-<ts>/`，建议加 `.gitignore` 忽略。
